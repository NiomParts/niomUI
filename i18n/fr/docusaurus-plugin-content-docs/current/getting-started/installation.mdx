# Installation

Niom Parts prend en charge React 18 et React 19.

```bash
npm install niom-parts
```

## Styles

L'entrée principale du paquet inclut automatiquement les styles compilés. Un import de composant normal suffit :

```tsx title="src/main.tsx"
import React from "react";
import ReactDOM from "react-dom/client";
import { Button } from "niom-parts";
import App from "./App";

ReactDOM.createRoot(document.getElementById("root")!).render(<App />);
```

Pour les outils CSS ou une chaîne de compilation qui attend une feuille de style explicite, ces chemins facultatifs pointent vers le même fichier :

```tsx
import "niom-parts/style.css";
import "niom-parts/css";
import "niom-parts/css/index.css";
```

La même feuille de style facultative peut être chargée depuis un fichier CSS :

```css
@import "niom-parts/style.css";
```

## Prérequis

| Paquet | Version prise en charge |
| --- | --- |
| React | `^18.0.0` ou `^19.0.0` |
| React DOM | `^18.0.0` ou `^19.0.0` |
| Node.js pour le développement | `^20.19.0` ou `>=22.12.0` |
