# Icon

Niom exporte un ensemble de composants d'icones SVG legers. Chaque icone accepte les proprietes SVG standard ainsi que `size`, `width`, `height`, `color` et `className`.

## Cas d'utilisation courants

Les icones decoratives doivent etre masquees aux technologies d'assistance, tandis que les boutons composes uniquement d'une icone necessitent un libelle accessible.

```jsx live
function IconUseCases() {
  return (
    <div className="flex flex-wrap items-center gap-3">
      <Button leftIcon={<Search size={18} aria-hidden="true" />}>
        Rechercher
      </Button>
      <Button aria-label="Add to favorites" variant="outline">
        <Heart size={19} />
      </Button>
      <span className="inline-flex items-center gap-2 text-accent">
        <Check size={18} aria-hidden="true" />
        Payment confirmed
      </span>
      <ArrowRight size={28} color="var(--color-secondary)" />
    </div>
  );
}
```

## Proprietes

| Propriete      | Type                      | Valeur par defaut |
| -------------- | ------------------------- | ----------------- |
| `size`         | `number \| string`        | icon-specific     |
| `width`        | `number \| string`        | -                 |
| `height`       | `number \| string`        | -                 |
| `color`        | `string`                  | `"currentColor"`  |
| `className`    | `string`                  | -                 |
| SVG attributes | `SVGProps<SVGSVGElement>` | -                 |
