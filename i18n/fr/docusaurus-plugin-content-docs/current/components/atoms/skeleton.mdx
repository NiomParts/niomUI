# Skeleton

Skeleton cree des espaces reserves neutres avec une animation facultative et des angles configurables.

```jsx live
function SkeletonExample() {
  return (
    <div className="grid w-72 gap-4">
      <div className="flex items-center gap-3">
        <Skeleton className="size-12" rounded="full" />
        <div className="grid flex-1 gap-2">
          <Skeleton className="h-4 w-2/3" />
          <Skeleton className="h-3 w-full" />
        </div>
      </div>
      <Skeleton className="h-36 w-full" rounded="lg" />
    </div>
  );
}
```

```tsx
import { Skeleton } from "niom-parts";

<Skeleton className="h-40 w-full" rounded="lg" />
```

## Cas d'utilisation courants

Adaptez les espaces reserves a la mise en page finale afin d'eviter les decalages pendant le chargement.

```jsx live
function SkeletonUseCases() {
  return (
    <div className="grid w-full max-w-lg gap-5">
      <Card className="grid gap-3">
        <Skeleton className="h-5 w-1/3" />
        <Skeleton className="h-3 w-full" />
        <Skeleton className="h-3 w-4/5" />
      </Card>
      <div className="grid grid-cols-[3rem_1fr_5rem] items-center gap-3">
        <Skeleton className="size-12" rounded="full" />
        <Skeleton className="h-4 w-full" />
        <Skeleton className="h-9 w-full" rounded="md" animated={false} />
      </div>
    </div>
  );
}
```

## Proprietes

| Propriete | Type | Valeur par defaut |
| --- | --- | --- |
| `animated` | `boolean` | `true` |
| `rounded` | `"none" \| "sm" \| "md" \| "lg" \| "full"` | `"md"` |
| `className` | `string` | - |
| HTML attributes | `HTMLAttributes<HTMLDivElement>` | - |
